# Spring Boot Thymeleaf Demo

A Java web application demonstrating server-side HTML rendering with Spring Boot and Thymeleaf.

## Overview
This repository explores the integration of Spring Boot controllers, model data, and Thymeleaf templates. Review the source to see the pages and workflows implemented.

## Technology
- Java
- Spring Boot
- Thymeleaf
- Build dependencies declared by the project

## Getting Started
1. Install the JDK version required by the project.
2. Clone the repository:
   ```bash
   git clone https://github.com/MahiTzy/springboot-thymeleaf-demo.git
   cd springboot-thymeleaf-demo
   ```
3. Review the application configuration and set any required external dependencies.
4. Run with the Maven wrapper if present:
   ```bash
   ./mvnw spring-boot:run
   ```
   Otherwise use the configured build tool.

## Application Flow
Explore the controller methods, model attributes, and templates to understand how server-side views are rendered.

## Development
Use the project's build tasks to run tests and package the application. Keep secrets and local configuration out of Git.
